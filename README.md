# 🪄 Dtwo Starter Templates

> Quickly get started with a minimal Dtwo starter template!

## Usage

You can use `dtwc` CLI to clone latest template to an empty directory:

```sh
$ npx dtwc init [-t,--template=<template>] [<dir>]
```

**Example:** Clone `v3` to `my-app` directory:

```sh
$ npx dtwc init -t v3 dtwo-app
```

## Templates

| Name                                          | Description | Local                           |
| --------------------------------------------- | ----------- | ------------------------------- |
| [v3](https://github.com/dtwo/starter/tree/v3) | Dtwo 3      | `npx dtwc init dtwo-app`        |
| [v2](https://github.com/dtwo/starter/tree/v2) | Dtwo 2      | `npx dtwc init dtwo2-app -t v2` |
